# MLOps Bootcamp Labs

This folder contains a simple lab sequence for the fraud MLOps project.

Lab 1 and Lab 2 introduce the basics:

- MQTT with Mosquitto
- MLflow experiment tracking

The later labs continue from there and connect the full project:

- data ingestion
- training
- model registry
- serving
- dashboarding
- monitoring
- orchestration
- Docker and CI

## Lab Order

1. Mosquitto publisher/subscriber
2. MLflow tracking and artifacts
3. Data ingestion to SQLite
4. Training pipeline
5. Model registry
6. Serving API and MQTT prediction
7. Grafana dashboard
8. Evidently monitoring
9. Prefect, Docker, and CI

The `src/` folder contains the working implementation. The labs explain the main ideas and point to the files students should inspect or run.
